## About This Project

This website documents my hands-on lab work completed during the **Next Chapter Software Engineering Apprenticeship** (April 2026 – August 2026). Each week covers new concepts in full-stack development, and each day's lab is recorded and published here as a video.

Labs are organized by week and day, and cover everything from basic prompting techniques to building and deploying AI-powered full-stack applications.

## Curriculum

The apprenticeship covers professional full-stack development, combining front-end and back-end skills with AI integration:

- **Front-End:** HTML, CSS, JavaScript (ES6+), React, Next.js, Responsive Design, Accessibility
- **Back-End:** Server APIs, Database (SQL), CI/CD pipelines
- **AI & Automation:** Anthropic Claude (LLM), ChatGPT, AI as thinking and building partners, Model Context Protocol (MCP), n8n, Zapier, third-party tool integration
- **Cloud & Infrastructure:** AWS cloud-native architecture, deploying services, managing server-side infrastructure
- **Python:** Fundamentals, data structures, script automation
- **Tools:** Replit, GitHub, VS Code, Claude, ChatGPT
